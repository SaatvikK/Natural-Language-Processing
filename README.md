# CS918 Assignment 2 — Sentiment Classification for Twitter/X  (CS918)

Builds tweet sentiment classifiers for SemEval 2017 Task 4, Subtask A. The task asks for at least two traditional ML classifiers (e.g. Naive Bayes, SVM, MaxEnt) trained on different feature sets, plus an LSTM in PyTorch with a frozen embedding layer initialised from 100-d GloVe vectors. Each classifier is trained on the training set and scored separately on three test sets, using macro-averaged F1 over the positive and negative classes.
